# Cell: repo-state

## Scope
Read-only repository orientation and implementation-state audit.

## Task
Inspect the repository structure, entry points, major modules, configuration, existing tests, and recent implementation state. Identify what is clearly complete, incomplete, or blocked.

## Constraints
- Do not edit production code.
- Do not modify files outside this cell's eventual REPORT.md.
- Do not add dependencies.

## Report
Create `.mece/cells/repo-state/REPORT.md` containing:
- inspected paths
- current architecture/state
- completed areas
- incomplete areas
- blockers/risks
- concrete verification commands
- session id if available
