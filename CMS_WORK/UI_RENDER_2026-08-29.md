# UI RENDER 2026-08-29 — карта красивого отображения ApiUI

Общий модуль: `static/api_render.js` (`window.ApiUI`), стили: `static/style.css` (`.api-*`).

## Примитивы ApiUI
| Примитив | Назначение |
|---|---|
| `badge(text, tone)` | пилл-бейдж: ok/bad/warn/info/flat |
| `statGrid([{label,value,sub,color}])` | карточки статистики |
| `gauge(value, max, label, warn)` | прогресс-бар с цветом |
| `table(headers, rows)` | таблица с ячейками-объектами `{html, style}` |
| `kv(obj)` / `pretty(k)` | KV-список, русские подписи (LABELS) |
| `formatValue`, `cellNum`, `cellColored`, `cellPct`, `cellTime` | форматирование ячеек |
| `signColor`, `time` | цвет P/L (зелёный/красный), даты (мс и ISO) |

## Правило
- Числа/деньги — через `num`/`num6` (моно-шрифт); % и P/L — с цветом `signColor`.
- Статусы/булевы — `badge`; даты — `time` (ISO и миллисекунды).
- Медиа-правило <640px: таблицы переходят в карточки, стат-grid в 2 колонки.
