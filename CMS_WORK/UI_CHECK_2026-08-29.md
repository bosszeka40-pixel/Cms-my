# UI CHECK 2026-08-29 — проверка html/js/css/функций и выдаваемой информации

Read-only проверка страниц, JS-функций и того, что они выводят. Код не менялся.
Среда: сервер `python3 run.py` (127.0.0.1:8000), Playwright chromium, авторизация через dev-admin-bypass.

## Методика
1. `node --check` всех `static/*.js`.
2. Playwright-свип всех 15 маршрутов: статусы HTTP, console-ошибки, pageerror, text-маркеры («NaN», «undefined», «Ошибка сети», «Недоступно») в body после рендера.
3. Перехват всех ответов со статусом >=400 (URL + статус).
4. Реальные пользовательские действия: отправка ордера, тест стратегии, выполнение стратегии, подключение кошелька, демо-режим.

## Результаты

### Синтаксис JS — OK
`api_render.js`, `cms_sections.js`, `market_live.js`, `market_terminal.js`, `market_terminal_patch.js`, `trading_chart.js` — `node --check` без ошибок.

### Загрузка страниц — OK
Все 15 маршрутов открываются со статусом 200. При чистой загрузке **0 реальных ошибок** ни на одной странице:
- pageerror: 0 (ранее зафиксированные `showDirectoryPicker/showOpenFilePicker/showSaveFilePicker` — артефакт авто-вызова нативных браузерных API тестовым скриптом, к страницам отношения не имеют).
- console errors: только `Failed to load resource: 404 /favicon.ico` на каждой странице — в проекте не определен favicon.
- text-маркеры «NaN»/«undefined»/«Ошибка сети»/«Недоступно» в body: не найдены ни на одной странице.

### HTTP 400/404/422 — разобраны, всё ожидаемое
| URL | Статус | Причина |
|---|---|---|
| `/favicon.ico` | 404 | favicon не задан (косметика, на каждой странице) |
| `/api/trading/manual` (пустая форма) | 400 | бэкенд-валидация: «Цена и количество должны быть положительными» — показывается пользователю как дружелюбная ошибка через `errBox` |
| `/api/wallet/connect` (пустая форма) | 422 | FastAPI-валидация; в UI выводится `badge('Ошибка') + detail` |
| `/wallpaper`, прямые не-роуты | 404 | не существующие маршруты; в UI не линкуются |

Ранее виденные 400 на `/strategies`, `/bot-management`, `/manual-trading` — артефакт вызова `loadChartData()` без аргументов из теста. В приложении функция вызывается только с параметрами (`loadChartData(pairEl.value, exchange, currentTf)`), при загрузке страниц 400 не возникает.

### Интерактивные действия — OK
- `/manual-trading` → «Отправить ордер» с пустыми полями: аккуратная ошибка «Ошибка | Цена и количество должны быть положительными.» (бэкенд-400 рендерится).
- «Запустить тест» и «Выполнить» (`/api/strategy/execute`): отрабатывают, ответ рендерится в `#tst-result`/`#exe-result` стат-гридами ApiUI, без ошибок.
- `/wallet` → «Подключить» пустой формой: 422 → дружелюбная ошибка.
- `/demo`: стат-грид «Режим DEMO 100€ / Баланс / Сделок / P/L» из `/api/demo/status|history|balance`; история сделок рендерится в таблицу. Текущие значения (баланс 0,00€, P/L −100,00€) — результат предыдущих тестовых сделок, не баг.
- `/strategies`: канвас графика `#test-chart` создаётся, `initTradingChart` + `loadChartData` отрабатывают.

### Соответствие форматов (API → рендер)
Сверено фактически получаемое в браузере с OpenAPI:
- `/api/market/news` `{news:[{source,title,url,published_at}]}` → карточки с пиллом источника + `ApiUI.time`.
- `/api/market/trending` `{trending:{name:{...}}}` и `/api/market/listings` `{listings:[{name,price_eur,description,category,monthly_return_pct,win_rate_pct,owned}]}` → таблица/карточки.
- `/api/bot/brain|config|memory|generation-status`, `/api/risk/status`, `/api/ai-shadow/*` → стат-гриды/таблицы ApiUI без NaN/undefined.
- `/api/demo/status` `{demo_active, demo_balance, demo_trades_count, demo_pnl}` → стат-грид; цвета P/L через `signColor`.
