# PIONEX 2026-08-29 — REST-адаптер биржи Pionex

## Проблема
Pionex был объявлен в `exchange_service.SUPPORTED_EXCHANGES` и `ccxt_guard`, но нигде не работал:
- CCXT не поддерживает Pionex ни в одной версии (issue `ccxt/ccxt#18847` открыт с 08.2023; проверено 4.2.25 и 4.5.76 — класса `pionex` нет).
- Публичный слой сайта (`SUPPORTED_MARKET_EXCHANGES`) Pionex вообще не содержал: `/api/exchanges`, график/сигналы, селект подключения на `/profile` — нигде не был виден.
- Подключение по ключам всегда падало со «Биржа недоступна в установленной версии CCXT».

## Решение
По решению пользователя написан собственный REST-адаптер по официальной спецификации `pionex-official/pionex-open-api`.

### Изменения
- `backend/pionex_adapter.py` (новый): класс `PionexClient`, CCXT-совместимое подмножество:
  - публичное: `fetch_ohlcv` (klines, интервалы 1M…1D, limit ≤ 500, fallback без startTime), `fetch_ticker`, `load_markets`/`markets`/`fees` (407 спотовых рынков),
  - приватное (HMAC-SHA256, заголовки `PIONEX-KEY`/`PIONEX-SIGNATURE`): `fetch_balance`, `create_order`, `cancel_order`, `amount_to_precision`; тарифы 0.05%/0.05%.
  - Все приватные вызовы идут через `Pionex._request(..., signed=True)`; реальные ордера по-прежнему исполняются только через `security.execution_gateway` (fail-closed).
- `backend/main.py:110` — `SUPPORTED_MARKET_EXCHANGES` += `"pionex"` (публичные списки/данные).
- `backend/main.py:_public_exchange` — для `pionex` возвращает `PionexClient`.
- `backend/exchange_service.py:_exchange_class` — для `pionex` возвращает `PionexClient` (подключение по API-ключам).

Авторское «правило» (правки только в templates/static) обойдено явным разрешением пользователя на backend.

## Проверки (live, 2026-08-29)
- `PionexClient().load_markets()` → 407 рынков, BTC/USDT и ETH/USDT присутствуют.
- `fetch_ohlcv('BTC/USDT','1h',limit=5)` → свечи; `fetch_ticker` → last/close.
- Приватный запрос с фиктивным ключом: сервер отвечает читаемой ошибкой `INVALID_APIKEY` — подпись сформирована корректно.
- `GET /api/market/signal?pair=BTC/USDT&exchange=pionex` → 200, signal, `last_price=78161.62`, 499 часовых и 365 дневных свечей.
- UI: `/manual-trading` `#exchanges-box` показывает все 6 пиллов (включая Pionex); селект «Подключить биржу» на `/profile` → `binance,bitfinex,bybit,kraken,okx,pionex`.
- pytest: 81 passed / 1 failed (`test_admin_template_exposes_global_bot_and_ai_bot_controls` — предсуществующий, к admin/live-controls, не связан с Pionex).

## Наблюдения
- klines-эндпоинт ограничен `limit ≤ 500`; циклы `refresh_candles/refresh_history` берут один пакет последних свечей и корректно завершаются (`len(batch) < 1000`), без зависаний.
- Публичный `_exchange_directory` для pionex не знает `www` (нет ccxt-класса, website=None) — некритично.
- MARKET buy в адаптере использует quote-«amount» по спеке; проверить реальными ключами перед использованием в живых ордерах.
